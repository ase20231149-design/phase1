# arXiv Hybrid Information Retrieval System

## 1. Project Overview
This project collects research papers from arXiv and builds a hybrid
information retrieval system combining BM25 and Dense Retrieval.
The two ranking lists are fused using Reciprocal Rank Fusion (RRF).

## 2. Data Collection
- Data source: arXiv API
- Selected category: cs.CV (Computer Vision)
- Date range: 2023-01-01 to 2026-10-31
- Total collected papers: 593

## 3. Research Subtopics
- Object Detection: 150 papers
- Pose Estimation: 149 papers
- Image Segmentation: 148 papers
- Medical Imaging: 146 papers

## 4. Corpus Statistics
- Short papers (<6 pages): 28
- Medium papers (7-9 pages): 81
- Long papers (>9 pages): 460
- Unclassified (exactly 6 pages): 24
- Average page count: 17.07
- Average extracted characters: 58,649.53
- Successful text extractions: 593
- Failed text extractions: 0

Note: Papers with exactly 6 pages are unclassified because the
assignment does not specify a category for this page count.

## 5. Retrieval Methods
### BM25
A sparse retrieval method based on term frequency and term importance.

### Dense Retrieval
A semantic retrieval method using sentence embeddings generated by
the all-MiniLM-L6-v2 model.

### Hybrid Retrieval
Combines BM25 and Dense Retrieval rankings using Reciprocal Rank Fusion.
The RRF parameter k is set to 60.

## 6. Query Processing
- Case-insensitive query processing.
- Spelling correction using TextBlob.
- Abbreviation expansion for selected terms such as AI, CV, and CNN.
- Exact phrase matching for quoted phrases.

## 7. User Interface
The Streamlit application provides:
- A search input field.
- A retrieval method selector: BM25, Dense, or Hybrid.
- The top 10 search results.
- Paper title, arXiv ID, and original paper link.
- Subtopic, ranking score, and a text snippet.

## 8. Installation
Install the required dependencies:
```bash
pip install -r requirements.txt
```

## 9. Running the Application
Run the following command from the project directory:
```bash
python -m streamlit run app.py
```

## 10. Main Project Files
- app.py: Streamlit interface and retrieval functions.
- data/corpus.csv: Corpus metadata and extraction information.
- data/corpus.pkl: Saved corpus.
- data/documents.json: Extracted document texts.
- data/collection_info.json: Data collection settings.
- models/bm25_model.pkl: Saved BM25 model.
- models/document_embeddings.npy: Dense document embeddings.
- reports/: Corpus statistics report.

## 11. Embedding Model
- Model: all-MiniLM-L6-v2
- Embedding dimensions: 384

## 12. Note
Keep the data and models directories in their expected locations
relative to app.py before running the application.
